# aglink 음성

말로 묻고, 답을 소리로 들어요. 받아쓰기와 읽어 주기는 모두 이 PC 안에서 돌아요.

| 할 일 | 방법 |
|---|---|
| 음성 켜기 · 끄기 | 상태 표시줄의 **음성**, 또는 **Ctrl+Alt+V** |
| 대화 시작 | "아글링크" 라고 부르기 (호출어 방식일 때) |
| 읽기 멈추기 | **Esc**, "잠깐", 또는 **Ctrl+Alt+Enter** |
| 들은 말 바로 보내기 | **Ctrl+Alt+Enter** |
| 대화 끝내기 | "그만" |
| 메뉴 | 음성 버튼 옆의 **▾** |

말 명령은 명령 팔레트의 **aglink 음성: 말 명령 도움말** 에서 모두 볼 수 있어요.
