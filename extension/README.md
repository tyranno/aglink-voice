# aglink 음성 — Claude Code 음성 대화

VS Code 의 Claude Code 에 말로 묻고, 답을 소리로 들어요. 받아쓰기, 읽어 주기,
등록한 목소리만 받기, "아글링크" 호출어가 모두 이 PC 안에서 돌아요. 인터넷으로
소리를 보내지 않아요.

## 쓰는 법

- 아래 상태 표시줄의 **음성** 을 누르거나 **Ctrl+Alt+V** 를 누르면 켜져요.
- 기본은 호출어 방식이에요. "아글링크" 라고 부르면 띵 소리가 나고 대화가
  시작돼요. "아글링크, 테스트 돌려 줘" 처럼 이어서 말해도 돼요.
- 말한 것은 Claude Code 입력칸에 들어가 바로 보내지고, 답이 끝나면 요점을
  읽어 줘요. 다 읽으면 다시 들어요.
- "그만" 하면 대화를 끝내고 다시 호출어를 기다려요. 3분 동안 말이 없어도
  그래요.

## 처음 한 번: 내 목소리 등록

명령 팔레트에서 **aglink 음성: 내 목소리 등록 (15초)** 을 고르거나, 대화 중에
"목소리 등록해 줘" 라고 하세요. 15초 동안 평소처럼 말하면 그 뒤로는 다른 사람
목소리와 스피커 소리를 보내지 않아요.

## 말로 바꾸는 것

| 말 | 하는 일 |
|---|---|
| 여자 삼 번 목소리로 바꿔 줘 / 다른 목소리로 바꿔 줘 | 읽는 목소리 (남자 1~5, 여자 1~5) |
| 좀 더 천천히 말해 줘 / 빨리 읽어 줘 / 속도 원래대로 | 빠르기 |
| 자세히 읽어 줘 / 요약해서 읽어 줘 / 다시 읽어 줘 | 방금 답 다시 읽기 |
| 글로만 보여 줘 / 다시 말로 해 줘 | 읽지 않고 글로만 |
| 잠깐 | 읽기 멈춤 |
| 새 대화 시작해 줘 | Claude Code 새 대화 |
| 부르는 이름을 자비스로 바꿔 줘 | 호출어 바꾸기 |
| 목소리 등록해 줘 / 목소리 등록 해제해 줘 | 목소리 등록·지우기 |

## 설정

상태 표시줄의 **음성** 을 누르면 메뉴가 떠요. 켜고 끄기, 목소리·빠르기 고르기,
들어 보기, 자주 바꾸는 켜짐/꺼짐 설정이 있고, 맨 아래 **설정 화면 열기** 를
누르면 모든 설정이 설명과 함께 한 화면에 나와요 (명령 팔레트의 **aglink 음성:
설정 화면 열기** 도 같아요).

- **타이핑한 질문 답도 읽기**: 손으로 입력한 질문의 답도 소리로 읽어 줘요.
  음성 대화를 켜지 않아도 되고 마이크는 쓰지 않아요.
- **말로 물어도 답은 글로만**: 말로 물은 질문의 답을 읽지 않고 글로만 보여 줘요.
- **읽는 중에 말하면 멈추기**(끼어들기): 헤드셋을 쓸 때 켜는 게 좋아요.

VS Code 기본 설정 화면(**설정 → aglink 음성**)에서도 같은 것을 바꿀 수 있어요.

## aglink 데스크톱 앱이 있으면

데스크톱 앱이 켜져 있으면 그 앱의 음성을 그대로 써요(설정도 데스크톱 앱을
따라요). 늘 이 확장의 엔진을 쓰려면 설정 `aglinkVoice.source` 를
`standalone` 으로 바꾸세요.
