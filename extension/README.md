# aglink 음성 — Claude Code 음성 대화

VS Code 의 Claude Code 에 말로 묻고, 답을 소리로 들어요. 받아쓰기, 읽어 주기,
등록한 목소리만 받기, "아글링크" 호출어가 모두 이 PC 안에서 돌아요. 인터넷으로
소리를 보내지 않아요.

## 쓰는 법

- 아래 상태 표시줄의 **음성** 을 누르거나 **Ctrl+Alt+V** 를 누르면 켜져요.
- 기본은 호출어 방식이에요. "아글링크" 라고 부르면 띵 소리가 나고 대화가
  시작돼요. "아글링크, 테스트 돌려 줘" 처럼 이어서 말해도 돼요.
- 말한 것은 Claude Code 입력칸에 들어가 바로 보내지고, 답이 끝나면 요점을
  읽어 줘요. 다 읽으면 다시 들어요.
- "그만" 하면 대화를 끝내고 다시 호출어를 기다려요. 3분 동안 말이 없어도
  그래요.

## 처음 한 번: 내 목소리 등록

명령 팔레트에서 **aglink 음성: 내 목소리 등록 (15초)** 을 고르거나, 대화 중에
"목소리 등록해 줘" 라고 하세요. 15초 동안 평소처럼 말하면 그 뒤로는 다른 사람
목소리와 스피커 소리를 보내지 않아요.

## 말로 바꾸는 것

| 말 | 하는 일 |
|---|---|
| 여자 삼 번 목소리로 바꿔 줘 / 다른 목소리로 바꿔 줘 | 읽는 목소리 (남자 1~5, 여자 1~5) |
| 좀 더 천천히 말해 줘 / 빨리 읽어 줘 / 속도 원래대로 | 빠르기 |
| 자세히 읽어 줘 / 요약해서 읽어 줘 / 다시 읽어 줘 | 방금 답 다시 읽기 |
| 글로만 보여 줘 / 다시 말로 해 줘 | 읽지 않고 글로만 |
| 잠깐 | 읽기 멈춤 |
| 새 대화 시작해 줘 | Claude Code 새 대화 |
| 부르는 이름을 자비스로 바꿔 줘 | 호출어 바꾸기 |
| 목소리 등록해 줘 / 목소리 등록 해제해 줘 | 목소리 등록·지우기 |

## 설정

상태 표시줄의 **음성** 을 누르면 메뉴가 떠요. 켜고 끄기, 목소리·빠르기 고르기,
들어 보기, 자주 바꾸는 켜짐/꺼짐 설정이 있고, 맨 아래 **설정 화면 열기** 를
누르면 모든 설정이 설명과 함께 한 화면에 나와요 (명령 팔레트의 **aglink 음성:
설정 화면 열기** 도 같아요).

- **타이핑한 질문 답도 읽기**: 손으로 입력한 질문의 답도 소리로 읽어 줘요.
  음성 대화를 켜지 않아도 되고 마이크는 쓰지 않아요.
- **말로 물어도 답은 글로만**: 말로 물은 질문의 답을 읽지 않고 글로만 보여 줘요.
- **읽는 중에 말하면 멈추기**(끼어들기): 헤드셋을 쓸 때 켜는 게 좋아요.
  켜 두면 말소리가 시작되자마자(0.25초쯤) 읽기를 멈춰요(`aglinkVoice.bargeFast`,
  기본 켜짐). 멈춘 뒤 들은 말이 질문이 아니면 다시 읽지 않고 다음 말을 들어요.
- **보낼 곳**(`aglinkVoice.target`): Claude Code(기본), Codex, 자동(마지막으로
  띄웠거나 답한 쪽). Codex 의 답을 읽으려면 명령 팔레트의 **aglink 음성: Codex 답
  읽기 설정** 을 한 번 실행하세요. `~/.codex/config.toml` 에 넣을
  `notify = [...]` 줄을 보여 주고, **추가** 를 누를 때만 써요. Codex 는 notify 를
  하나만 실행하므로, 이미 다른 프로그램의 `notify` 가 있으면(예: Codex 앱의
  `codex-computer-use.exe`) **같이 쓰기** 를 누를 때만 aglink 줄이 그 자리를
  맡고 원래 프로그램을 `--then` 뒤에 그대로 적어 두어 매번 먼저 실행해요. 누르지
  않으면 바꾸지 않아요. Node.js 가 있어야 하고, 바꾼 뒤에는 Codex 를 다시 열어야
  해요. 답을 읽을 설정이 없을 때 Codex 로 보내면 답을 기다리지 않고 바로 다시
  들어요. 설정 화면(**aglink 음성: 설정 화면 열기**)의 **보낼 곳** 에서도 고를 수 있어요.
- **말로 보낼 곳 정하기**: 앞에 이름을 붙여 "코덱스한테 테스트 돌려 줘",
  "클로드야, 로그 봐 줘" 처럼 말하면 설정과 상관없이 그 말만 그쪽으로 보내요(이름은
  빼고 보내요). 끝에 "… 라고 코덱스한테 전해 줘" 처럼 붙여도 돼요. "코덱스 설정
  열어 줘" 처럼 이름 뒤에 한테/에게/야나 쉼표가 없으면 그냥 질문으로 보내요.
  보낼 곳이 자동이면 다음 질문도 마지막으로 부른 쪽으로 가요.

답은 그 답의 질문이 지금 기다리는 질문일 때만 읽어요. 앞서 물은 질문의 답이
늦게 오면(호출어로 새로 물었을 때 등) 읽지 않고 넘겨요.

VS Code 기본 설정 화면(**설정 → aglink 음성**)에서도 같은 것을 바꿀 수 있어요.

### Remote-SSH에서 Codex 쓰기

Codex를 SSH 서버에서 실행한다면 원격 폴더를 연 창에서 **Codex 답 읽기 설정**을
실행하세요. aglink-vscode 0.4.9에 포함된 aglink-bridge 0.2.1과 원격 서버의
Node.js가 필요해요. **추가**를 누르면 원격 Codex 설정에 알림을 등록하고 답변은
같은 VS Code 창의 브리지를 거쳐 PC의 음성 확장으로 돌아옵니다.
알림 줄에는 브리지가 서버에서 찾은 node 의 절대 경로가 들어가요(로그인 셸,
대화형 셸의 nvm, 없으면 VS Code 서버의 node 순). Codex 는 서버의 PATH 에 node 가
없을 때가 많기 때문이에요. 예전에 넣은 줄이 맨 이름 "node" 이거나 지워진 VS Code
서버의 node 를 가리키면 브리지가 켜질 때 고치고, 같은 명령을 다시 열면 **갱신**
으로 바꿀 수도 있어요.
SSH 창을 다시 불러온 뒤에는 Codex를 새로 열고, 터미널에서 실행한다면 새 통합
터미널을 사용하세요.

## 단어장과 스니펫

명령 팔레트의 **aglink 음성: 단어장 열기** (또는 음성 메뉴·설정 화면의
**단어장 열기**) 를 고르면 `~/.aglink/voice-words.json` 이 열려요. 없으면 빈
파일을 만들어요. aglink 데스크톱 앱과 같은 파일이라 한쪽에서 고치면 양쪽에
쓰이고, 저장하면 다음 말부터 적용돼요.

```json
{
  "words": ["Headscale", "두원"],
  "replace": [{ "from": "에이지링크", "to": "aglink" }],
  "snippets": [{ "trigger": "내 메일 주소", "text": "doowon@example.com" }]
}
```

- **words**: 받아쓰기가 자주 틀리는 이름·용어. 받아쓰기에 힌트로 줘요(짧게
  유지돼요 — 너무 많으면 뒤쪽 말이 빠져요).
- **replace**: 받아 적은 말에서 `from` 을 `to` 로 바꿔요. 띄어쓰기("에이지
  링크")와 영문 대소문자는 가리지 않고, 긴 말부터 맞춰 봐요. 영문 단어 안의
  일부("said" 속 "ai")는 바꾸지 않아요.
- **snippets**: `trigger` 를 말하면 그 자리에 `text` 를 넣어요. 그 말만 하면
  `text` 만 보내요. 여러 줄 글도 줄바꿈 그대로 들어가요.

## aglink 데스크톱 앱이 있으면

데스크톱 앱이 켜져 있으면 그 앱의 음성을 그대로 써요(설정도 데스크톱 앱을
따라요). 늘 이 확장의 엔진을 쓰려면 설정 `aglinkVoice.source` 를
`standalone` 으로 바꾸세요.
